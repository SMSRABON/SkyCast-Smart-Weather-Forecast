# 🌦️ SkyCast — Smart Weather & Forecast

**SkyCast** is a modern, responsive, and user-friendly weather forecasting web application built with HTML, CSS, and JavaScript. It provides real-time weather updates, hourly and 7-day forecasts, air quality information and weather-related notices in one convenient dashboard.

The application supports both English and Bangla languages, along with dark and light themes, making weather information accessible and easy to understand.

## 🌐 Live Demo

[Visit SkyCast – Smart Weather & Forecast](https://smsrabon.github.io/SkyCast-Smart-Weather-Forecast/)

## ✨ Features

### 🌤️ Weather Information
- Real-time weather updates for different cities.
- Search weather by city name.
- Current location weather using GPS.
- Current temperature and feels-like temperature.
- Daily maximum and minimum temperatures.
- Humidity, wind speed, atmospheric pressure and UV index.

### 📅 Weather Forecast
- 24-hour hourly weather forecast.
- 7-day weather forecast.
- Daily rain probability.
- Sunrise and sunset times.

### 🌫️ Air Quality Monitoring
- US Air Quality Index (AQI).
- PM2.5 and PM10 monitoring.
- Ozone (O₃) information.
- Nitrogen Dioxide (NO₂) information.
- Air quality condition and health guidance.

### ⚠️ Weather Notices
- Rain alerts.
- Thunderstorm notices.
- High-temperature notices.
- Low-temperature notices.
- Strong-wind notices.
- High UV index notices.
- Poor air quality notices.

### 🎨 User Interface
- Modern and responsive dashboard.
- Dark mode and light mode.
- English and Bangla language support.
- Interactive OpenStreetMap integration.
- Automatic weather data refresh every 15 minutes.
- Remembers the last searched location and theme using Local Storage.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and responsive design |
| JavaScript | Application functionality |
| Open-Meteo API | Weather forecast data |
| Open-Meteo Geocoding API | City search |
| Open-Meteo Air Quality API | Air quality information |
| OpenStreetMap | Location map |
| Browser Geolocation API | Current location detection |
| Local Storage | Saving user preferences |

 
## 🌍 Data Sources & APIs

- **Open-Meteo Weather API:** https://open-meteo.com/
- **Open-Meteo Geocoding API:** https://open-meteo.com/en/docs/geocoding-api
- **Open-Meteo Air Quality API:** https://open-meteo.com/en/docs/air-quality-api
- **OpenStreetMap:** https://www.openstreetmap.org/

## 📱 Compatibility

SkyCast is designed for modern web browsers and supports desktop, tablet and mobile devices.

**Note:** An active internet connection is required to retrieve weather data and maps. Location-based weather requires browser location permission and a secure connection such as HTTPS.
